# YANGShopping

보안 중심의 온라인 쇼핑몰을 구축합니다.

## Stack
- Python
- FastAPI
- PostgreSQL
- React

## Security
- 비밀번호 마스킹
- 입력 검증
- 환경 변수 관리
- 로그 마스킹
- JWT 토큰 인증
- CSRF 보호
- XSS 방지

## Features
- 상품 카탈로그 관리
- 장바구니 관리
- 주문 및 결제
- 배송 조회
- 관리자 대시보드

- 설계: 요구사항 분석 및 기능 설계
- 구현: API 서버 구현
- 구현: React 클라이언트 구현
- 구현: 데이터베이스 스키마 설계 및 구현
- 테스트: 단위 테스트 및 통합 테스트
- 배포: Docker 이미지 빌드 및 배포
- 배포: CI/CD 파이프라인 설정
