# 보안 중심 통합 쇼핑몰 및 영상 교육 플랫폼

Python 기반 FastAPI 백엔드와 React 프론트엔드를 사용한 보안 중심 쇼핑몰 및 영상 교육 플랫폼으로, 관리자/사용자/운영자 보안 흐름을 포함합니다.

## Stack
- Python
- FastAPI
- React
- PostgreSQL
- Dart
- Kotlin
- Java

## Security
- 비밀번호 마스킹 및 강력한 해싱
- 입력 검증 및 SQL 인젝션 방지
- 환경 변수 관리 및 민감 정보 보호
- 로그 마스킹 및 보안 로그 관리
- RBAC 기반 권한 제어
- 세션 및 토큰 관리

## Features
- 사용자 인증 및 권한 관리 (JWT 기반)
- 결제 및 배송 시스템 통합
- 영상 교육 콘텐츠 관리 및 재생
- 관리자 대시보드 및 모니터링
- 보안 중심 데이터 마스킹 및 환경 변수 관리

## Tasks
- 설계: 도메인 모델링 및 보안 흐름 설계
- 설계: API 설계 및 인증/권한 시스템 설계
- 구현: 백엔드 API 및 서비스 로직 구현
- 구현: 프론트엔드 UI 및 모바일 앱 구현
- 구현: 보안 모듈 및 데이터 마스킹 로직 구현
- 테스트: 단위 테스트 및 통합 테스트
- 테스트: 보안 테스트 및 침해 테스트
- 배포: CI/CD 파이프라인 구축 및 배포
- 배포: 모니터링 및 로그 관리 시스템 설정
