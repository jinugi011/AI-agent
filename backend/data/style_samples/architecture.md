# 코딩 스타일 가이드

- 보안은 항상 우선이다. 비밀번호, 토큰, 결제 정보, 개인정보는 마스킹하고 환경 변수로 관리한다.
- 프로젝트는 API, 서비스, 저장소, UI 계층으로 분리한다.
- 요청 처리에서 입력 검증, 에러 핸들링, 로그 기록을 반드시 수행한다.
- PostgreSQL, Redis, 메시지 큐를 활용해 데이터와 비즈니스 로직을 분리한다.
- 모바일/웹/관리자 화면은 각각의 책임을 분리하고 재사용 가능한 컴포넌트로 구성한다.
- 코드 문서화와 테스트는 구현의 일부로 간주한다.
- 쇼핑몰 프로젝트는 상품, 주문, 관리자 대시보드, 결제 흐름, 권한 기반 접근을 중심으로 설계한다.
- 영상 교육 서비스는 강의 관리, 수강 이력, 댓글/리뷰, 결제 및 사용자 학습 진도 추적을 포함한다.
- 모바일 앱 프로젝트는 인증, 사용자 프로필, 알림, 데이터 동기화, 오프라인 대응을 우선적으로 고려한다.
- 공통 규칙: 값 검증, 역할 기반 접근 제어, 민감정보 로그 금지, 응답 포맷 표준화, 테스트 가능한 서비스 분리.
